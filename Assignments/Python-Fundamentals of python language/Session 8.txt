Q-2 : Write a function extract_artist(song_title) that takes a string in the format 'Song Name - Artist Name' (like you see on Spotify) and returns just the artist's name using string slicing.<br><br><em><strong>Hint:</strong> Use the index() method to find the position of the dash.</em>
Ans:

def extract_artist(song_title):
    dash_index = song_title.index("-")
    return song_title[dash_index+1:].strip()





Q-3 : Build a function reverse_message(message) that reverses any string passed to it, similar to how WhatsApp displays reversed text stickers.<br><br><em><strong>Constraint:</strong> Do not use Python's built-in reversed() or [::-1] slicing shortcut.</em>
Ans:

def reverse_message(message):
    return "".join(message[index] for index in range(len(message) - 1, -1, -1))





Q-4 : Given a Flipkart product description string, write a Python script that extracts and prints the first word, last word, and the total number of words using string methods split(), indexing, and len().
Ans:

description = input("Enter product description: ")
words = description.split()

print("First word:", words[0])
print("Last word:", words[-1])
print("Total words:", len(words))





Q-5 : Create a function mask_phone_number(phone) that takes a 10-digit phone number as a string and returns it in the format '******1234', showing only the last 4 digits like Paytm does.<br><br><em><strong>Hint:</strong> Use string slicing and concatenation.</em>
Ans:

def mask_phone_number(phone):
    return "******" + phone[-4:]

print(mask_phone_number("9876541234"))
