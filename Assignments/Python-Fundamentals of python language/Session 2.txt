Q-4 : Given the following variables for a YouTube video — title, views, likes, is_premium — identify which are primitive and which are non-primitive data types, and explain your reasoning in comments.
Ans.

title = "Python Tutorial"  # Non-primitive (str)
views = 10000              # Primitive (int)
likes = 500                # Primitive (int)
is_premium = True          # Primitive (bool)

# Primitive Data Types:
# views is a primitive data type (int) because it stores a whole number.
# likes is a primitive data type (int) because it stores a whole number.
# is_premium is a primitive data type (bool) because it stores True or False.

# Non-Primitive Data Types:
# title is a non-primitive data type (str) because it stores text.
# A string is a sequence of characters.
# It supports indexing and slicing.
