In `stock.py` write `add_item(inventory, name, qty, price)`, which stores name: {'qty': qty, 'price': price} in a dictionary, and `low_stock(inventory, limit=5)`, which returns the names of items with quantity at or below the limit. In 'run_shop.py', saved next to the folder, import `stock` from the package, add 6 fictional items and print the low-stock names. Hint: Run 'run_shop.py' from the folder that contains `hardware_shop`.</p>
Ans:

def add_item(inventory, name, qty, price):
    inventory[name] = {
        "qty": qty,
        "price": price
    }


def low_stock(inventory, limit=5):
    low_items = []

    for name, details in inventory.items():
        if details["qty"] <= limit:
            low_items.append(name)

    return low_items

Q-2 : <p>Add a module `pricing.py` to the `hardware_shop` package with `gst_amount(price, rate=18)` and `cart_total(inventory, cart)`, where `cart` is a dictionary of item name to quantity bought. `cart_total` returns the total including GST, rounded to 2 decimals, and prints a message and skips any cart item missing from the inventory. Import `pricing` in 'run_shop.py' and print the total for a cart of 3 items. Constraint: Use an `if ... in` check; do not use try/except.</p>
Ans:

def gst_amount(price, rate=18):
    gst = price * rate / 100
    return gst


def cart_total(inventory, cart):
    total = 0

    for name, qty in cart.items():

        if name in inventory:
            price = inventory[name]["price"]
            amount = price * qty

            gst = gst_amount(amount)
            total += amount + gst

        else:
            print(name, "is not available in inventory. Skipping.")

    return round(total, 2)
