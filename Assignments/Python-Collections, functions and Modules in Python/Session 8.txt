Q-1 : <p>Write a function `monthly_emi(principal, annual_rate, years)` in a file named 'loan_emi_calculator.py' that returns the monthly EMI using EMI = P x r x (1 + r)^n / ((1 + r)^n - 1), where r is the annual rate divided by 12 and by 100, and n is years x 12. Call it with positional arguments for ₹5,00,000 at 9% for 5 years and print the EMI rounded to 2 decimals. Hint: `**` is the power operator; your answer should be close to ₹10,379.18.</p>
Ans:

def monthly_emi(principal, annual_rate, years):
    r = annual_rate / 12 / 100
    n = years * 12

    emi = principal * r * (1 + r) ** n / ((1 + r) ** n - 1)

    return emi


emi = monthly_emi(500000, 9, 5)

print("Monthly EMI: ₹", round(emi, 2))

Q-3 : <p>Add a function `loan_summary(principal, annual_rate=10.5, years=3, fee_percent=1)` to 'loan_emi_calculator.py' that returns a tuple of EMI, total payable, total interest and processing fee in ₹, each rounded to 2 decimals. Call it as `loan_summary(300000, fee_percent=0.5)` and print each value with a label. Constraint: Inside `loan_summary`, call `monthly_emi` using keyword arguments.</p>
Ans:

def monthly_emi(principal, annual_rate=10.5, years=3):
    r = annual_rate / 12 / 100
    n = years * 12

    emi = principal * r * (1 + r) ** n / ((1 + r) ** n - 1)

    return emi


def loan_summary(principal, annual_rate=10.5, years=3, fee_percent=1):
    emi = monthly_emi(
        principal=principal,
        annual_rate=annual_rate,
        years=years
    )

    total_payable = emi * years * 12
    total_interest = total_payable - principal
    processing_fee = principal * fee_percent / 100

    return (
        round(emi, 2),
        round(total_payable, 2),
        round(total_interest, 2),
        round(processing_fee, 2)
    )


emi, total, interest, fee = loan_summary(300000, fee_percent=0.5)

print("Monthly EMI: ₹", emi)
print("Total Payable: ₹", total)
print("Total Interest: ₹", interest)
print("Processing Fee: ₹", fee)

def monthly_emi(principal, annual_rate=10.5, years=3):
    r = annual_rate / 12 / 100
    n = years * 12

    emi = principal * r * (1 + r) ** n / ((1 + r) ** n - 1)

    return emi


def loan_summary(principal, annual_rate=10.5, years=3, fee_percent=1):
    emi = monthly_emi(
        principal=principal,
        annual_rate=annual_rate,
        years=years
    )

    total_payable = emi * years * 12
    total_interest = total_payable - principal
    processing_fee = principal * fee_percent / 100

    return (
        round(emi, 2),
        round(total_payable, 2),
        round(total_interest, 2),
        round(processing_fee, 2)
    )
