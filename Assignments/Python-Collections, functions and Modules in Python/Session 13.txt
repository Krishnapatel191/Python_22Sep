Q-1 : <p>Create 'expense_matrix.py' with a nested list `expenses` of 6 rows (January to June) and 4 columns (food, transport, rent share, entertainment), with every amount between ₹500 and ₹15,000. Use a list comprehension to build `month_totals`, one total per row, and print each month with its total. Hint: `[sum(row) for row in expenses]`; `sum()` adds up the numbers in a list.</p>
Ans:

expenses = [
    [3000, 1200, 8000, 1500],    # January
    [3500, 1000, 8000, 2000],    # February
    [2800, 1500, 8000, 1800],    # March
    [4000, 1200, 8000, 2500],    # April
    [3200, 1300, 8000, 2000],    # May
    [3800, 1400, 8000, 2200]     # June
]

months = ["January", "February", "March", "April", "May", "June"]

month_totals = [sum(row) for row in expenses]

for i in range(len(months)):
    print(months[i], "Total: ₹", month_totals[i])





Q-2 : <p>Add a nested list `by_category` to 'expense_matrix.py' with 4 inner lists, each holding one category's 6 monthly amounts, built with a nested list comprehension. Print each category's name with its total. Hint: The outer comprehension runs over the column numbers `range(4)`, and the inner one picks `row[c]` from every row.</p>
Ans:

expenses = [
    [3000, 1200, 8000, 1500],    # January
    [3500, 1000, 8000, 2000],    # February
    [2800, 1500, 8000, 1800],    # March
    [4000, 1200, 8000, 2500],    # April
    [3200, 1300, 8000, 2000],    # May
    [3800, 1400, 8000, 2200]     # June
]

months = ["January", "February", "March", "April", "May", "June"]

categories = ["Food", "Transport", "Rent Share", "Entertainment"]

month_totals = [sum(row) for row in expenses]

print("Monthly Expenses:")
for i in range(len(months)):
    print(months[i], "Total: ₹", month_totals[i])

    [row[c] for row in expenses]
    for c in range(4)
]

print("\nCategory-wise Expenses:")

for i in range(len(categories)):
    print(categories[i], "Total: ₹", sum(by_category[i]))





Q-3 : <p>Build `big_expenses` in 'expense_matrix.py', a flat list of (month name, category name, amount) tuples for every amount above ₹5,000, using one list comprehension with two `for` clauses and an `if`. Q-4 : <p>Finish 'expense_matrix.py' by building `savings_plan`, a nested list in which the transport and entertainment amounts are cut by 10% (rounded to a whole rupee) and the other columns stay the same, using a nested comprehension with a conditional expression. Print the old and new total for every month. Paste the output as a comment at the end of the file. Constraint: Do not use `append()` or loops outside comprehensions for this step.</p>
Ans:

expenses = [
    [3000, 1200, 8000, 1500],    # January
    [3500, 1000, 8000, 2000],    # February
    [2800, 1500, 8000, 1800],    # March
    [4000, 1200, 8000, 2500],    # April
    [3200, 1300, 8000, 2000],    # May
    [3800, 1400, 8000, 2200]     # June
]

months = ["January", "February", "March", "April", "May", "June"]

categories = ["Food", "Transport", "Rent Share", "Entertainment"]

month_totals = [sum(row) for row in expenses]

print("Monthly Expenses:")
for i in range(len(months)):
    print(months[i], "Total: ₹", month_totals[i])

by_category = [
    [row[c] for row in expenses]
    for c in range(4)
]

print("\nCategory-wise Expenses:")
for i in range(len(categories)):
    print(categories[i], "Total: ₹", sum(by_category[i]))

big_expenses = [
    (months[i], categories[j], expenses[i][j])
    for i in range(len(months))
    for j in range(len(categories))
    if expenses[i][j] > 5000
]

print("\nBig Expenses:")
for item in big_expenses:
    print(item)

savings_plan = [
    [
        round(amount * 0.9) if c == 1 or c == 3 else amount
        for c, amount in enumerate(row)
    ]
    for row in expenses
]

new_totals = [sum(row) for row in savings_plan]

print("\nOld and New Monthly Totals:")
for i in range(len(months)):
    print(
        months[i],
        "Old Total: ₹", month_totals[i],
        "| New Total: ₹", new_totals[i]
    )
