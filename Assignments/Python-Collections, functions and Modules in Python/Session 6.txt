Q-1 : <p>Create 'tuition_fee_book.py' with two lists of 8 entries for a fictional tuition class: `students` (names) and `fees` (monthly fee in ₹, between 800 and 2,500). Use `zip()` to convert them into a dictionary named `fee_book`, then loop with `items()` and print one 'name: ₹fee' line per student.</p>

Q-3 : <p>Combine the two dictionaries in 'tuition_fee_book.py' into one nested dictionary `ledger`, where each student maps to {'fee': ..., 'status': ...}. Build it with a loop over `fee_book.items()`. Print the total pending amount in ₹ and the number of students who have paid.</p>
Ans:

students = [
    "Rahul", "Priya", "Amit", "Neha",
    "Krishna", "Meera", "Rohan", "Pooja"
]

fees = [1200, 1500, 1800, 1000, 2000, 1600, 2200, 1400]

fee_book = dict(zip(students, fees))

status = [
    "Paid", "Pending", "Paid", "Pending",
    "Paid", "Pending", "Paid", "Pending"
]

paid_status = {}

for i in range(len(students)):
    paid_status[students[i]] = status[i]

ledger = {}

for name, fee in fee_book.items():
    ledger[name] = {
        "fee": fee,
        "status": paid_status[name]
    }

print("===== Tuition Fee Ledger =====")

for name, details in ledger.items():
    print(name, ":", details)

pending_amount = 0
paid_count = 0

for name, details in ledger.items():
    if details["status"] == "Pending":
        pending_amount += details["fee"]

    elif details["status"] == "Paid":
        paid_count += 1

print("\nTotal Pending Amount: ₹", pending_amount)
print("Number of Paid Students:", paid_count)





Q-4 : <p>Finish 'tuition_fee_book.py' with a function `lists_to_dict(keys, values)` that returns the dictionary, but prints 'Lists differ in length' and returns an empty dictionary when the two lists have different lengths. Use it for `ledger`. Test with your 8 names and 8 fees, and with 8 names and 7 fees. Paste both outputs as a comment at the end of the file. Hint: `len()` works on lists.</p>
Ans:

def lists_to_dict(keys, values):
    if len(keys) != len(values):
        print("Lists differ in length")
        return {}

    result = {}

    for i in range(len(keys)):
        result[keys[i]] = values[i]

    return result


students = [
    "Rahul", "Priya", "Amit", "Neha",
    "Krishna", "Meera", "Rohan", "Pooja"
]

fees = [1200, 1500, 1800, 1000, 2000, 1600, 2200, 1400]

status = [
    "Paid", "Pending", "Paid", "Pending",
    "Paid", "Pending", "Paid", "Pending"
]

fee_book = lists_to_dict(students, fees)
paid_status = lists_to_dict(students, status)

ledger = {}

for name, fee in fee_book.items():
    ledger[name] = {
        "fee": fee,
        "status": paid_status[name]
    }

print("===== Ledger =====")

for name, details in ledger.items():
    print(name, ":", details)

short_fees = [1200, 1500, 1800, 1000, 2000, 1600, 2200]

print("\n===== Length Mismatch Test =====")
