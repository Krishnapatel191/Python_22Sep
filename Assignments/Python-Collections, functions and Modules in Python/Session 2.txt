Q-1 : <p>Create a file named 'cricket_innings.py' with a list `overs` holding the runs scored in each of 20 overs by a fictional team, 'Sabarmati Strikers', with every value between 0 and 22. Use a for loop directly on the list to calculate and print the total score and the number of overs in which 10 or more runs were scored.</p>
Ans:

team = "Sabarmati Strikers"

overs = [8, 12, 5, 18, 10, 6, 15, 9, 20, 4,
         11, 7, 14, 22, 3, 16, 8, 13, 19, 6]

total_score = 0
high_scoring_overs = 0

for runs in overs:
    total_score = total_score + runs

    if runs >= 10:
        high_scoring_overs = high_scoring_overs + 1

print("Team:", team)
print("Total Score:", total_score)
print("Overs with 10 or more runs:", high_scoring_overs)

Q-3 : <p>Add a list `cumulative` to 'cricket_innings.py' that holds the running total after each over, built with a loop over `range(len(overs))` and `append()`. Print each over's running total next to its runs. Hint: For index `i` above 0, the running total is `cumulative[i - 1] + overs[i]`; the first over is just `overs[0]`.</p>
Ans:

team = "Sabarmati Strikers"

overs = [8, 12, 5, 18, 10, 6, 15, 9, 20, 4,
         11, 7, 14, 22, 3, 16, 8, 13, 19, 6]

high_scoring_overs = 0

for runs in overs:
    total_score = total_score + runs

    if runs >= 10:
        high_scoring_overs += 1

# Print over-wise runs
print("\nOver-wise Runs:")

for i in range(len(overs)):
    print("Over", i + 1, ":", overs[i])

highest_runs = overs[0]
lowest_runs = overs[0]
highest_over = 1
lowest_over = 1

for i in range(len(overs)):
    if overs[i] > highest_runs:
        highest_runs = overs[i]
        highest_over = i + 1

    if overs[i] < lowest_runs:
        lowest_runs = overs[i]

print("\nHighest Runs:", highest_runs)

cumulative = []

for i in range(len(overs)):
    if i == 0:
        cumulative.append(overs[i])
    else:
        cumulative.append(cumulative[i - 1] + overs[i])

print("\nOver-wise Running Total:")

for i in range(len(overs)):
    print("Over", i + 1, "| Runs:", overs[i],
          "| Running Total:", cumulative[i])






Q-4 : <p>Finish 'cricket_innings.py' by printing the over number in which the running total first reached 50, 100 and 150, or 'not reached' when it never did. Run the program for your 20-over list and for a second list of only 8 overs, so that it works with any list length. Paste both outputs as a comment at the end of the file. Hint: Use `len(overs)` instead of the number 20.</p>
Ans:

def check_targets(cumulative):

    for target in [50, 100, 150]:
        found = False

        for i in range(len(cumulative)):
            if cumulative[i] >= target:
                print(target, "runs first reached in Over:", i + 1)
                found = True
                break

        if not found:
            print(target, "runs: not reached")


print("\nMilestone Check - 20 Overs:")
check_targets(cumulative)

overs_8 = [8, 12, 5, 18, 10, 6, 15, 9]
