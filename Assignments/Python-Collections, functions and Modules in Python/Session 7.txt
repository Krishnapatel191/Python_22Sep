Q-1 : <p>Create 'fest_feedback.py' with a string `feedback` of at least 60 lowercase words, made of 5 invented visitor comments about a fictional college fest. Build a dictionary `char_freq` that counts how many times each letter appears, ignoring spaces and punctuation, and print every letter and its count in alphabetical order. Hint: `ch.isalpha()` filters letters; check `if ch in char_freq` before adding one to a count. Constraint: Count with a for loop; do not use `count()`.</p>
Ans:

feedback = """
the college fest was amazing and full of exciting activities
the music performance was wonderful and everyone enjoyed dancing together
the food stalls offered delicious snacks and refreshing drinks for all visitors
the decoration was beautiful and the volunteers were friendly and helpful
the games competitions and cultural performances made the entire event memorable
"""

char_freq = {}

for ch in feedback:
    if ch.isalpha():
        if ch in char_freq:
            char_freq[ch] += 1
        else:
            char_freq[ch] = 1

print("===== Character Frequency =====")

for ch in sorted(char_freq):
    print(ch, ":", char_freq[ch])

Q-4 : <p>Finish 'fest_feedback.py' by wrapping the word counting in a function `analyse(text)` that prints total words, unique words and the top word for any text the user types with `input()`. Print 'No words found' for empty text. Test with an empty text, 'Great food, great music, great crowd!' (top word: great, 3 times) and one comment of your own. Paste the outputs as a comment at the end of the file.</p>
Ans:

def analyse(text):
    clean_text = text.lower()

    for ch in ".,!?":
        clean_text = clean_text.replace(ch, "")

    words = clean_text.split()

    if len(words) == 0:
        print("No words found")
        return

    word_freq = {}

    for word in words:
        if word in word_freq:
            word_freq[word] += 1
        else:
            word_freq[word] = 1

    total_words = len(words)
    unique_words = len(word_freq)

    stop_words = ['the', 'and', 'was', 'a', 'is', 'to']

    top_word = ""
    highest_count = 0

    for word, count in word_freq.items():
        if word not in stop_words:
            if count > highest_count:
                highest_count = count
                top_word = word

    print("Total words:", total_words)
    print("Unique words:", unique_words)

    if top_word == "":
        print("Top word: No suitable word found")
    else:
        print("Top word:", top_word, "-", highest_count, "times")


feedback = input("Enter your feedback: ")

analyse(feedback)
