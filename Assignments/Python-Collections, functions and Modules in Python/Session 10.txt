Q-1 : <p>Create a module file named 'library_utils.py' with a function `days_late(issue_day, return_day)`, which returns how many days a book is late when it is kept more than 14 days (0 if not late), and `fine_amount(late_days, per_day=2)`, which returns the fine in ₹. In 'library_main.py', saved in the same folder, use `import library_utils` and print the fine for a book issued on day 10 and returned on day 31. Hint: Run 'library_main.py', not the module. Constraint: Do not call `print()` or `input()` at the top level of the module.</p>
Ans:

def days_late(issue_day, return_day):
    days_kept = return_day - issue_day

    if days_kept > 14:
        return days_kept - 14
    else:
        return 0


def fine_amount(late_days, per_day=2):
    return late_days * per_day

Q-2 : <p>Add `issue_book(register, member, title, issue_day)` and `books_of(register, member)` to 'library_utils.py'. `issue_book` appends a dictionary with those four details to the `register` list, and `books_of` returns the titles issued to that member. In 'library_main.py', bring them in with `from library_utils import issue_book, books_of`, issue 5 books to 3 invented members and print each member's titles.</p>
Ans: 

def days_late(issue_day, return_day):
    days_kept = return_day - issue_day

    if days_kept > 14:
        return days_kept - 14
    else:
        return 0


def fine_amount(late_days, per_day=2):
    return late_days * per_day


def issue_book(register, member, title, issue_day):
    register.append({
        "member": member,
        "title": title,
        "issue_day": issue_day
    })


def books_of(register, member):
    titles = []

    for book in register:
        if book["member"] == member:
            titles.append(book["title"])

    return titles

_____library_main.py

import library_utils as lib

register = []

while True:
    print("\n===== Library Menu =====")
    print("1. Issue Book")
    print("2. Return Book and Show Fine")
    print("3. Exit")

    choice = int(input("Enter your choice: "))

    if choice == 1:
        member = input("Enter member name: ")
        title = input("Enter book title: ")
        issue_day = int(input("Enter issue day: "))

        lib.issue_book(register, member, title, issue_day)

        print("Book issued successfully!")

    elif choice == 2:
        member = input("Enter member name: ")
        title = input("Enter book title: ")
        issue_day = int(input("Enter issue day: "))
        return_day = int(input("Enter return day: "))

        late = lib.days_late(issue_day, return_day)
        fine = lib.fine_amount(late)

        print("Book:", title)
        print("Loan Period:", lib.LOAN_DAYS, "days")
        print("Days Late:", late)
        print("Fine Amount: ₹", fine)

    elif choice == 3:
        print("Thank you for using Library System!")
        break

    else:
        print("Invalid choice!")
